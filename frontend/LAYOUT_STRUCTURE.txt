Responsive Breakpoints:
-----------------------

Desktop (> 1100px):     [Rail] [Sidebar] [Main] [Right]
Tablet  (820-1100px):   [Rail] [Sidebar] [Main]
Mobile  (600-820px):    [Rail] [Main]
Small   (< 600px):      [Main]

CSS Custom Properties:
----------------------
--bg: #f5f5f5           Background
--panel: #ffffff        Panels/cards
--border: #e0e0e0       Borders
--text: #213547         Text
--muted: #666666        Muted text
--accent: #667eea       Accent color
--radius: 8px           Border radius

Component Props:
----------------
<DesktopLayout
  showRail={true}           // Show/hide 56px rail
  showSidebar={true}        // Show/hide 260px sidebar
  showRightSidebar={true}   // Show/hide 320px right sidebar
>
  <YourContent />
</DesktopLayout>

Integration Examples:
---------------------

1. Full Layout:
   <DesktopLayout>
     <HomePage />
   </DesktopLayout>

2. Focus Mode (no right sidebar):
   <DesktopLayout showRightSidebar={false}>
     <DiscussionLive />
   </DesktopLayout>

3. Minimal Layout (content only):
   <DesktopLayout showRail={false} showSidebar={false} showRightSidebar={false}>
     <FullscreenView />
   </DesktopLayout>
